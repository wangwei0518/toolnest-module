# 文件邮局

文件邮局支持在设备之间暂存和分享文件、文字和链接。未配置 R2 时，文件分片上传至服务器的私有模块数据目录；配置 R2 后，新文件改为浏览器直传私有存储桶。登录用户创建投递，接收方通过分享链接和提取码访问。到期或撤销后停止签发新授权并清理内容。

## 运行条件

- ToolNest React 平台与独立 Node 运行时；模块后端使用 Node 内置 SQLite，要求 Node.js 22.13 或更新版本（该能力目前仍为实验性）。
- R2 可选。本地模式无需云凭证，设置页的 R2 字段可以全部留空；容量与期限仍可保存。本地文件位于 `TOOLNEST_PLUGIN_DATA_DIR/local-files`，签名密钥也在数据目录中，不能放在公开静态目录或活动 release 内。
- 使用 R2 时准备私有标准存储桶和仅限该桶的 Object Read & Write 凭证；请勿启用公开开发域名或公开读取策略。在模块设置中填写账号 ID、桶名及凭证，密钥不回显、不进入发布包。
- R2 模式需在桶 CORS 中允许实际 HTTPS 源；允许 `PUT`、`GET`、`HEAD` 并公开 `ETag`。CORS 不提供鉴权，桶仍需保持私有。
- 宿主后端必须包含可信管理员身份转发及模块网关 `application/octet-stream` 流式转发支持。设置页提示“宿主未传递管理员身份”时，应更新并重启宿主后端；不能通过放开模块管理员校验解决。
- 本地上传每片最多 5 MiB，反向代理应允许至少 6 MiB 请求体，并给低速上传足够时间；模块网关请求超时为 180 秒。下载经过服务器出口，3 Mbps 服务器的速度和其他业务会共享。本地合并文件需要额外临时磁盘空间，应预留至少一个最大文件的余量。
- 使用 HTTPS 并配置平台的公开访问地址和反向代理，使分享页面可由接收设备访问；带宽受接收设备与 R2 之间网络影响。

设置和 SQLite 数据、分享密钥均位于模块的 `TOOLNEST_PLUGIN_DATA_DIR`。备份和迁移时应一并保存整个数据目录，并限制访问权限；丢失分享密钥可能导致已有提取码无法恢复。

## 使用与安全边界

- 文件大小、总配额、上传并发、默认和最长有效期由管理员配置；下载限制统计的是已签发的下载授权次数，不代表下载完成次数。次数用完后立即停止签发新授权；为避免影响最后一个有效链接，后台在其最长期限（两分钟）之后清理对象。
- 浏览器中断后可重新选择原文件，客户端核对已保存分片的 MD5 ETag 后继续；本地与 R2 均支持。不要依赖浏览器在后台持续上传。
- 每个文件保存实际存储位置；已有本地文件不会因后来配置 R2 而迁移。配额统计两种存储的保留内容，未完成上传也占用配额。R2 请求失败会报错，不会静默写入本地；仍有 R2 文件时不能移除或更换其桶配置。
- 提取码校验值与派生所需信息保存在模块数据中，不保存明文提取码。分享密钥保存在同一受限目录，管理员需要同时保护该目录及其备份。
- 短期下载地址在有效期内是访问凭证。本地下载每次检查投递是否撤销或过期，并支持 Range；R2 已签发地址仍可能在两分钟内有效。两种模式都不能保证终止已经开始的下载，内容不是端到端加密。
- R2 可能产生存储及操作费用。配额、生命周期规则与云端账单提醒应结合实际预算设置；应用的清理不能代替云端监控。

## 开发与交付

在平台仓库执行 `pnpm react:dev:temporary-transfer` 启动隔离的 Host 与模块 Vite 开发入口；后端按平台开发规范单独启动。该映射只在明确启用的开发进程中生效，不更改安装版本或活动 release。

正式交付时按平台和模块的测试标准执行受影响的类型检查、构建、UI 检查与浏览器回归，再按独立模块仓库的打包流程生成 `.tnmod`。开发环境通过运行时模块 API 上传安装或升级，并轮询 operation 至明确结果；不要直接映射源码到活动 release。

0.1.0 已完成隔离 HMR 的真实 R2 分片上传、刷新后续传、下载哈希及清理验证，并完成正式包的运行时安装、宿主渲染及匿名文字接收验证。平台全量回归仍有失败项，公网部署尚未执行，详细结果与边界见 [验证记录](./VERIFICATION.md)。

## 0.1.6 投递箱界面

- 采用已确认的 shadcn/Base UI 原型：双栏等高发送与取件卡片、紧凑按钮、设置旁的容量摘要；手机优先展示取件。
- 文件与文字切换维持卡片高度；多附件列表随数量增加显示空间。上传和接收均按文件类型展示附件，图片、文本/代码、PDF、音频、视频支持浏览器预览，Office/压缩包保留类型提示与下载。
- 同账号可查看最近有效投递；独立八位字母数字取件码可在登录后的投递箱接收内容。匿名接收方仍通过分享链接与六位数字提取码验证；访客输入为居中的 Basic 单组六位 OTP。
- 独立码使用域分离 HMAC 派生与唯一哈希索引；旧数据自动迁移且六位链接码不变，重新生成提取码时两个码一起失效。查码与下载分别限流，所有下载路径共用事务化授权计数。
- 预览由接收方点击后加载，每次签发地址计入下载授权。最大预览 25 MiB，文本只读前 64 KiB；HTML/SVG/代码只显示文本，不执行。R2 预览也需要桶 GET CORS。
- 匿名页保持 CSP，动态 OTP 样式使用每页随机 nonce，仅允许当前配置 R2 源连接及本地 Blob 媒体；不允许任意内联脚本。
- 开发入口通过启动进程的 `TOOLNEST_REACT_HOST_DEV_ORIGIN` 共享 Host 的 React；普通模块安装与正式包不依赖该设置。验收详情见 [验证记录](./VERIFICATION.md)。
